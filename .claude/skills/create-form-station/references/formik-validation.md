# Formik Validation Schema Generation

This document describes how to generate Yup validation schemas from GraphQL schema field metadata for Formik form validation.

## Overview

Validation schemas ensure form data meets requirements before submission. They are generated by:
1. Parsing GraphQL field annotations (`@maxLength`, `@notEmpty`, etc.)
2. Using field types (String, Int, etc.)
3. Mapping to Yup validation rules

## Basic Schema Structure

```typescript
import * as Yup from 'yup';
import { ObjectSchemaDefinition } from '@axinom/mosaic-ui';

const {entityLowerCase}CreateSchema = Yup.object().shape<
  ObjectSchemaDefinition<FormData>
>({
  // Field validations
});
```

## Validation Rules by Field Type

### String Fields

**Required string:**
```graphql
title: String!
```

```typescript
title: Yup.string().required('Title is a required field')
```

**With maxLength:**
```graphql
"""
@maxLength(100)
@notEmpty()
"""
title: String!
```

```typescript
title: Yup.string()
  .required('Title is a required field')
  .max(100)
```

**With minLength and maxLength:**
```graphql
"""
@minLength(3)
@maxLength(100)
"""
name: String!
```

```typescript
name: Yup.string()
  .required('Name is a required field')
  .min(3)
  .max(100)
```

### Number Fields (Int)

**Required integer:**
```graphql
index: Int!
```

```typescript
index: Yup.number()
  .positive('{Field} must be a positive number')
  .integer('{Field} must be an integer')
  .required('{Field} is a required field')
```

**Optional integer:**
```graphql
count: Int
```

```typescript
count: Yup.number()
  .positive('Count must be a positive number')
  .integer('Count must be an integer')
  .nullable()
```

### Float Fields

**Required float:**
```graphql
rating: Float!
```

```typescript
rating: Yup.number()
  .positive('Rating must be a positive number')
  .required('Rating is a required field')
```

### Boolean Fields

**Required boolean:**
```graphql
isActive: Boolean!
```

```typescript
isActive: Yup.boolean()
  .required('Is Active is a required field')
```

### Date Fields

**Required date:**
```graphql
released: Date!
```

```typescript
released: Yup.date()
  .required('Released date is a required field')
```

**Optional date:**
```graphql
published: Date
```

```typescript
published: Yup.date()
  .nullable()
```

### UUID Fields

**Required UUID:**
```graphql
videoId: UUID!
```

```typescript
videoId: Yup.string()
  .matches(
    /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i,
    'Must be a valid UUID'
  )
  .required('Video ID is a required field')
```

## Annotation to Yup Mapping

| GraphQL Annotation | Yup Rule | Example |
|-------------------|----------|---------|
| `@maxLength(N)` | `.max(N)` | `.max(100)` |
| `@minLength(N)` | `.min(N)` | `.min(3)` |
| `@notEmpty()` | Implied by `.required()` | Already handled |
| Field is required (`!`) | `.required('message')` | `.required('Title is required')` |
| Field is optional | `.nullable()` | `.nullable()` |

## Complete Examples

### Single Required Field (Collection)

**GraphQL Schema:**
```graphql
input CollectionInput {
  """
  @maxLength(100)
  @notEmpty()
  """
  title: String!
}
```

**Yup Schema:**
```typescript
const collectionCreateSchema = Yup.object().shape<
  ObjectSchemaDefinition<FormData>
>({
  title: Yup.string().required('Title is a required field').max(100),
});
```

### Multiple Required Fields (Episode)

**GraphQL Schema:**
```graphql
input EpisodeInput {
  index: Int!

  """
  @maxLength(100)
  @notEmpty()
  """
  title: String!
}
```

**Yup Schema:**
```typescript
const episodeCreateSchema = Yup.object<ObjectSchemaDefinition<FormData>>({
  title: Yup.string().required('Title is a required field').max(100),
  index: Yup.number()
    .positive('Episode Index must be a positive number')
    .integer('Episode Index must be an integer')
    .required('Episode Index is a required field'),
});
```

## Error Message Patterns

Use consistent, user-friendly error messages:

| Validation | Message Pattern |
|------------|-----------------|
| Required | `'{Field} is a required field'` |
| Max length | Handled automatically by Yup |
| Min length | Handled automatically by Yup |
| Positive number | `'{Field} must be a positive number'` |
| Integer | `'{Field} must be an integer'` |
| UUID format | `'Must be a valid UUID'` |

## Optional Fields

**Rule:** Do not add validation for optional fields in Create stations.

Create stations only show required fields, so optional field validation is not needed.

## Common Patterns

### String with MaxLength
```typescript
fieldName: Yup.string().required('{Field} is a required field').max(100)
```

### Positive Integer
```typescript
fieldName: Yup.number()
  .positive('{Field} must be a positive number')
  .integer('{Field} must be an integer')
  .required('{Field} is a required field')
```

### Optional Date
```typescript
fieldName: Yup.date().nullable()
```
